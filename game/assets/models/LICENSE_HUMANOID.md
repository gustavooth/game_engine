# Humanoid idle model

`humanoid_idle.glb` is the original rigged and animated `assets/human.glb`
from the UMRAM-Bilkent supine-human-model repository. It is a character by
Quaternius released under Creative Commons CC0 1.0.

- Model: https://github.com/UMRAM-Bilkent/supine-human-model/blob/main/assets/human.glb
- Attribution and license: https://github.com/UMRAM-Bilkent/supine-human-model#source--license
- Original creator: https://quaternius.com/
- License: https://creativecommons.org/publicdomain/zero/1.0/

The demo plays the model's `Human Armature|Idle` animation (clip 2).

The original `ClothedLightSkin.png` texture from Quaternius' Animated Human
pack is embedded in this GLB. It is also CC0 1.0:
https://opengameart.org/content/animated-human-low-poly
